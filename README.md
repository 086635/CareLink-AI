# CareLink-AI | 智护无忧

**基于智能纸尿裤与华为云的老年主动照护管理系统**

## 项目介绍

在养老机构中，护理人员需要定期检查老人的纸尿裤状态。传统的人工巡查不仅耗费时间，还可能无法及时发现需要更换纸尿裤的情况。

智护无忧希望通过智能纸尿裤和物联网技术，帮助护理人员及时发现照护需求。

当设备检测到尿湿信号时，系统会自动生成待核查事件，并提醒护理人员处理。护理人员可以通过手机查看任务、记录处理结果，管理人员则可以通过平台了解整体照护情况。

我们希望实现的不只是智能报警，而是让每一次照护需求都能够被发现、被处理、被记录。

## 计划实现的功能

- **智能设备监测**：接收纸尿裤传感器数据，查看设备状态。
- **护理事件提醒**：识别需要人工检查的事件并发送提醒。
- **护理任务管理**：支持任务认领、处理和记录。
- **AI 照护助手**：根据护理记录生成交接班摘要和照护分析。
- **机构管理平台**：展示护理任务、设备状态和运营数据。

## 技术方案

- 前端：Vue 3
- 后端：Spring Boot
- 数据库：华为云 RDS for MySQL
- 缓存：华为云 DCS for Redis
- 云端部署：华为云 ECS
- AI 辅助开发：华为云码道 CodeArts
